【0】受測態：5 qubit，RY 角度編碼 -> 環形 CX -> 2 層 RY+環形 CX
     Tr[rho]      = 1.000000000000000
     純度 Tr[rho^2] = 1.000000000000000   （純態應為 1.0）
     非對角 l1 同調 = 18.081706
     與 qubit0 的糾纏熵 S = 0.809748 bit

【1】驗證 (a)：機率分布會不會變？—— 答案取決於「用哪個基底量測」

  (a-1) 計算基底（Z 基底）下的 32 維分布：
        max |p_before - p_after| = 0.000e+00
        ==> 0。這是**定理**不是巧合：去相位只刪非對角元，而 Born 機率
            取的是對角元。所以「在 Z 基底量測」時去相位完全隱形。
            → 這一條必須誠實報告，否則整組消融會被老師一句話推翻。

  (a-2) X 基底（每個 qubit 先過 H 再量）下的 32 維分布：
        max |p_before - p_after| = 0.281923
        l1 距離  sum|p_before - p_after| = 1.179898
        ==> 明顯改變。因為 X 基底量的是非對角（同調）資訊。

        逐 qubit 的 <X> 對照（同調性最直接的證據）：
          qubit 0:  <X>_全量子 = +0.252436   <X>_去相位 = +0.000000   差 = +0.252436
          qubit 1:  <X>_全量子 = +0.247210   <X>_去相位 = +0.000000   差 = +0.247210
          qubit 2:  <X>_全量子 = +0.624600   <X>_去相位 = +0.000000   差 = +0.624600
          qubit 3:  <X>_全量子 = +0.253385   <X>_去相位 = +0.000000   差 = +0.253385
          qubit 4:  <X>_全量子 = +0.242986   <X>_去相位 = +0.000000   差 = +0.242986

【2】驗證 (b)：去相位後仍是合法密度矩陣
     |Tr[rho_cl] - 1|        = 2.220e-16
     Hermitian 誤差 max|rho-rho^dag| = 0.000e+00
     最小 eigenvalue          = 1.188e-04   （必須 >= 0）
     純度由 1.0000000000 降為 0.0902204631
     ==> 跡保（trace-preserving）成立。理由：cl 是 CPTP 通道，
         其 Kraus 算子 K_a=|a><a| 滿足 sum_a K_a^dag K_a = I【F1 L486/L526】。

【3】驗證 (c)：冪等性 cl(cl(rho)) = cl(rho)
     max|cl(cl(rho)) - cl(rho)|     = 0.000e+00
     max|cl^3(rho)   - cl(rho)|     = 0.000e+00
     ==> 冪等性成立（數值上是機器精度等級）。
         理論理由：cl 之後非對角元已全為 0，再遮罩一次沒有東西可刪；
         這與【F1 L374】的封閉性 tr_b cl_b = tr_b 同源。

     順帶檢查：cl 不可逆【F1 L438】——去相位後再補一個么正閘，
     同調性仍然回不來（見下方第 4 節的對照）。

【4】``cl`` 插在哪裡？三種插入位置 + 全量子對照

     設定                                Tr            純度        l1同調      maxΔPz      maxΔPx
     --------------------------------------------------------------------------------------
     (0) 全量子（對照）                 1.000000      1.000000   18.081706    0.000000    0.000000
     (1) 只在編碼層後 cl               1.000000      0.157754    7.386085    0.109924    0.252953
     (2) 在每個節點 cl【L53】           1.000000      0.052670    0.000000    0.126353    0.281923
     (3) 只在最後 cl                 1.000000      0.090220   -0.000000    0.000000    0.281923

  讀法：
   * 「在每個節點 cl」把同調性壓到 0（l1 同調 = 0），X 基底分布與全量子
     的差距最大 —— 這正是【F1 L53】所說的『退化為古典貝氏網路』。
   * 「只在最後 cl」同樣讓最終 rho 變成對角（非對角在最後一步被刪），
     但它**保留了中間過程的干涉**：中間的振幅相加已經發生、結果已經
     寫進對角元，所以 Z 基底分布與全量子完全相同。
   * 因此 A1 消融必須**明講插入位置**，否則「去相位」三個字是歧義的。
     本專案正式實驗採「在每個節點 cl」作為 A1 的處理臂，因為那才是
     【F1 L53】字面上的操作；「只在最後 cl」作為附帶的第二個處理臂，
     用來分離「中間干涉」與「最終讀出同調」兩項貢獻。

【5】實作自我檢查
     dephase() 內部已 assert「位元遮罩」與「投影算子夾擠」兩條路徑
     給出同一個矩陣（atol=1e-12），本執行未觸發 assert。
     第三條路徑（取部分跡後張量回對角）等價性另由 dev/labs 的

結論：去相位函式通過 (a) 分布改變（X 基底）、(b) 跡保、(c) 冪等 三項驗證。
