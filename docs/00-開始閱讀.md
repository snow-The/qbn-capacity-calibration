## 三十秒版

我們檢驗一個多數混合式量子—古典分類器論文**不會問**的問題：

> **量子層到底有沒有在做事情？**

既有工作在比較不同架構時，量子層是**兩邊都一樣的常數**——所以它們無法回答「量子性本身是否必要」。
我們把量子層變成**受控變因**（去相位古典化），並做了三項實驗：容量斷崖掃描、校準消融、**真機驗證**。

本專案**不主張任何量子優勢**：5 個 qubit 的狀態向量只有 512 位元組，完全可古典模擬。
我們提供的是**可完全驗證的管線**與**可證偽的實驗設計**。

## 指令速查

```bash
# 論文（Typst 是內容的單一真相，LaTeX 由它產生）
cd paper
python make_latex.py                    # Typst -> LaTeX
cmd /c build_all.bat                    # 圖 + 中文 + 英文（Typst）
cmd /c build_tex.bat                    # LaTeX -> PDF
cmd /c build_arxiv.bat                  # 產生 submission.zip

# 理論的數值驗證
python theory/verify/t5_commutator_placement.py     # 25/25 checks

# 形式化（需要 Lean 4 + mathlib）
cd <mathlib4> && lake env lean <this-repo>/formal/Dephasing.lean

# 發布前守衛
python tools/verify_repo.py             # credentials clean / 無大檔
```
