## 二、Tuna-17 真機：已釐清，資料已救回

**完整診斷見 `Tuna17-NoResults-診斷.md`。** 摘要：

- 真因：`job_execution_time_limit = 300 秒`（官方 OpenAPI spec 的 BackendType 欄位）。
  同一 batch 5 顆電路中若有慢電路（實測 215–235 秒），總時間超過上限 → job 被 CANCELLED。
- `qiskit-quantuminspire` 的 `_fetch_failed_jobs_message` 只檢查 `FAILED`，
  對 `CANCELLED` 填入字面上的 "No Results" → 誤導。
- **結果一直存在伺服器上**：93 個 job 中 72 個有完整結果，已存入 `results/recovered.json`。
- 官方 API 文件：`https://api.quantum-inspire.com/openapi.json`
