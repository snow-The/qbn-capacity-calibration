§3.1 未校準模型的基準數字
==============================================================================
準確率 = 0.6467
平均信心 = 0.7423   （信心 − 準確率 = +0.0957）
NLL      = 0.9442
ECE(M=10)= 0.0957

溫度縮放要做的事：把 logits 全部除以一個純量 T，讓分布『不那麼尖』。
    q = softmax(z / T),   T > 0
T 只有一個參數，在**驗證集**上以最大似然估計 —— 也就是最小化驗證集 NLL。

==============================================================================
§3.2 掃 T：驗證 top-1 標籤恆不變（Murphy L44113）
==============================================================================
掃描 T ∈ [0.2500, 20.0000]，共 240 個值
其中 top-1 標籤與 T=1 不同的次數：**0 次**
準確率的取值集合：[0.6466666667]  ← 只有一個值

★ 為什麼保證不變？softmax 是**單調**的：對固定的 x，
    argmax_c softmax(z/T)_c = argmax_c z_c    對所有 T > 0 都成立。
  除以正數只會重新縮放 logits，不會改變它們的大小順序。
  → **溫度縮放是「零準確率損失改善校準」的免費午餐。**
  → 反過來說：任何「我們的模型校準比較好」的主張，
    只要對手也能做溫度縮放，就必須贏過**已經縮放過**的對手。

§3.3 學習 T：驗證集上最小化 NLL
==============================================================================
T*（驗證集 NLL 最佳）        = 1.6766
T（驗證集 ECE 最佳）         = 1.4533
T（測試集 ECE 最佳，僅供對照，實務不可用）= 1.4010

                             準確率       ECE       NLL     Brier
------------------------------------------------------------------------------
未校準（T=1）                0.6467    0.0957    0.9442    0.4753
溫度縮放 T*=1.677           0.6467    0.0368    0.8730    0.4633
T=1.401（ECE 最佳）         0.6467    0.0223    0.8774    0.4623

→ 準確率三列完全相同（0.6467）。
→ NLL 最佳 T*=1.677 讓 ECE 從 0.0957 降到 0.0368（61.5% 的降幅）。
→ 但 ECE 自己最喜歡的 T 是 1.401，能到 0.0223。
  ★ 誠實提醒：**溫度縮放最小化的是 NLL，不是 ECE。**
    ECE 的改善是副產品。Murphy（L44056–L44113）引用的 [Guo+17] 觀察到
    它在多個 DNN 上『剛好』也拿到最低 ECE，但這不是定理。
    所以本專案必須同時報 NLL 與 ECE，不能只挑一個講。
  ★ 也**不可以**用測試集去挑 T —— 那是資料洩漏。上表第三列只是示範。

==============================================================================
§3.4 這對本專案的意義：量子層的校準優勢必須贏過 TS 基線
==============================================================================
把 §3.3 的數字翻譯成論證檢查表：

  [1] 你的量子模型（未校準）ECE      = ______   （本示範：0.0957）
  [2] 你的量子模型（溫度縮放後）ECE  = ______   （本示範：0.0368）
  [3] 古典基線（未校準）ECE          = ______
  [4] 古典基線（溫度縮放後）ECE      = ______   ← **這一格才是你的對手**

  若 [2] < [4]，你的結論是：『在相同校準後處理下，量子層帶來更好的校準。』
  若只比 [1] < [3]，你的結論只能寫：『我們的模型沒做校準後處理，對手也沒做。』
  → 後者會被一句話打掉：『你只是沒做溫度縮放而已。』

  ★ 本專案硬規則：**RQ2（去相位消融）的每一組對照，都要同時報
    未校準與溫度縮放後兩組 ECE。** 只報未校準的那一組不算數。
  ★ 額外要求 [4] 也要用**同一個驗證集**去擬合 T（不能各擬各的測試集），
    而且要去相位前後的兩個模型共用同一組資料切分。

==============================================================================
§3.5 溫度縮放不是萬靈丹：它修不了什麼
==============================================================================
溫度縮放只調整『整體的尖銳程度』（一個純量），因此：
  ✗ 修不了『同一個信心水準下，不同類別的準確率不同』（class-conditional 失準）
  ✗ 修不了分布偏移（Murphy L44125：[Ova+19] 指出良好校準的模型，
    遇到不同分布的輸入時常變得校準不良）
  ✗ 修不了『箱內震盪』型的失準（§2.5 偏差二）
  ✗ 不改變 top-1，所以對準確率一點幫助都沒有
  ✓ 只修得了『整條可靠度曲線一起被過度放大』這種最常見的失準

還有一個 T 治不了的例子：**類別條件失準（class-conditional miscalibration）**。
把 logits 做一個跟類別有關的變形：前 5 類乘 1.6（更尖）、後 5 類乘 0.6（更平）。
這樣『同一條可靠度曲線』的兩半需要相反的 T，一個純量 T 救不了。

                                         準確率       ECE       NLL
------------------------------------------------------------------------------
類別條件失準（T=1）                         0.4583    0.4218    3.3955
類別條件失準 + 全域 T*=4.820                0.4583    0.1053    1.3663
── 對照組 ──                                                     
原本的均勻失準（T=1）                        0.6467    0.0957    0.9442
原本的均勻失準 + 全域 T*=1.677               0.6467    0.0368    0.8730

→ 均勻失準：全域 T* 讓 ECE 從 0.0957 降到 0.0368（降 61.5%）。
→ 類別條件失準：全域 T* 讓 ECE 從 0.4218 降到 0.1053
  雖然也降了 75.0%，但**剩下的殘量 0.1053 仍是均勻失準修好後（0.0368）的 2.9 倍**。
  因為一個純量 T 只能整體伸縮，無法同時滿足『前 5 類要更平、後 5 類要更尖』。
  要修它得用**每類一個溫度**（class-wise temperature），但那已經是多參數模型，
  而且需要更多驗證資料才估得穩。

  → 這正是「量子層若真能改善校準，就不只是等價於一個溫度參數」的論證骨架：
    你要能指出**溫度縮放結構上做不到**的那種改善。
    ⚠ 反過來也要誠實：如果你的量子層改善**剛好等於一個 T**，
      那就必須承認『這個改善可以被一個純量的校準後處理取代』。
