==========================================================================
§1.1 兩個模型，同樣的準確率，不同的下場
==========================================================================
資料：1000 筆、10 類（每類 100 筆，完全平衡）；答對 950 筆

指標                        模型 A（宣稱 99%）            模型 B（誠實）          誰比較好
--------------------------------------------------------------------------
準確率                             0.9500              0.9500            一樣
平均信心                            0.9900              0.9519         B 較誠實
NLL（越低越好）                     0.3795              0.3080          B 較好
Brier（越低越好）                  0.0990              0.0972          B 較好
ECE（越低越好）                      0.0400              0.0019          B 較好

→ 準確率完全相同（都是 0.9500），但 ECE 差了 21 倍。
→ NLL 差 +0.0714（A 較差），這是因為 A 答錯時仍宣稱 0.99，
  真類別被壓到 (1-0.99)/9 ≈ 0.0011，-log(0.0011) ≈ 6.8 —— NLL 對這種事懲罰極重。

拆開看（同一批答錯的 50 筆）：
  模型 A 答錯時的平均 NLL = 7.3988
  模型 B 答錯時的平均 NLL = 5.2254
  → 差距 +2.1734，擴大了 30.4 倍。
  → 這就是為什麼「平均 NLL」會把危險模型洗白：95% 的答對樣本稀釋了 5% 的災難。

§1.2 類別不平衡時，準確率會說謊
==========================================================================
測試集：950 筆負類 + 50 筆正類（正類佔 5.0%）

模型                           準確率       精確率       召回率        F1
--------------------------------------------------------------------------
永遠說「負類」                 0.9500    0.0000    0.0000    0.0000
真的有在分類                  0.9200    0.3333    0.6000    0.4286

→ 懶惰分類器準確率 95%，召回率 0、F1 0：它一筆正類都沒抓到。
→ 真的在做事的模型準確率只有 92%（比較低！），卻抓到了 60% 的正類。
  如果你只看準確率，你會挑錯模型。這就是為什麼類別不平衡時
  一定要同時報 macro-F1 與 per-class 指標（ECE 也一樣，見 §2.5）。

§1.3 嚴格評分規則（strictly proper scoring rule）
==========================================================================
定義（Murphy, Advanced Topics, L43955–L43969）：
  S(p_theta, p*) <= S(p*, p*)    等號若且唯若 p_theta = p*
  白話：**只有誠實報告機率**才能拿到最好分數。
  準確率不是嚴格評分規則 —— 它只看 argmax，
  (0.99, 0.005, ...) 跟 (0.34, 0.33, 0.33) 在它眼裡一樣好。

(a) 只看單一筆已實現結果（真實標籤剛好是類別 0）：
報告方式                             NLL     Brier       q_0   top-1
--------------------------------------------------------------------------
誠實  q = p*                  0.5108    0.2350    0.6000       0
過度自信（往 0/1 推）               0.1181    0.0224    0.8886       0
過度保守（往均勻推）                  0.8557    0.4462    0.4250       0
  ⚠ 注意：過度自信的 NLL 反而最低！因為這一筆剛好答對了，
    把類別 0 推得更高自然得分更好。**這不是評分規則壞掉，
    而是「單一樣本的分數」本來就有運氣成分。**

(b) 對真實分布 p* 取期望（這才是 proper scoring rule 的定義）：
報告方式                            E[NLL]    E[Brier]
--------------------------------------------------------------------------
誠實  q = p*                    1.0331      0.5650
過度自信（往 0/1 推）                 1.4239      0.6813
過度保守（往均勻推）                    1.1291      0.6112

  → 誠實報告的 E[NLL] = 1.0331，正好等於真實分布的熵 H(p*) = 1.0331。
  → 任何偏離 p* 的報告方式（更尖或更平）期望分數都更差。
    這就是嚴格評分規則（Gibbs 不等式）：**誠實是唯一的最佳策略**。
  → 準確率沒有這個性質：三種報告方式的 top-1 標籤完全一樣，
    它在 (a) 看不出差別，在 (b) 也完全無法區分。

==========================================================================
§1.4 為什麼 Brier 有界而 NLL 無界
==========================================================================
          真類別被給的機率 p    NLL = -log p        Brier（單筆, C=4）
--------------------------------------------------------------------------
               9e-01          0.1054              0.013333
               5e-01          0.6931              0.333333
               1e-01          2.3026              1.080000
               1e-02          4.6052              1.306800
               1e-03          6.9078              1.330668
               1e-06         13.8155              1.333331
               1e-12         27.6310              1.333333

→ p → 0 時 NLL → ∞，Brier 卻飽和在 2（除以 C 後是 0.5）。
  推論：**如果你的模型偶爾會把正確類別壓到極低機率，NLL 會被那幾筆支配。**
  實務上要同時報兩個：Brier 看整體、NLL 看尾端災難。

==========================================================================
§1.5 反例：什麼樣的指標會被騙
==========================================================================
模型                               準確率       ECE       NLL     Brier
--------------------------------------------------------------------------
誠實（說 0.95）                  0.9500    0.0000    0.1985    0.0950
吹牛（說 0.999）                 0.9500    0.0490    0.3463    0.0998

→ 準確率一模一樣；ECE / NLL / Brier 一致地把吹牛的那個抓出來。
  這三個指標就是本專案「不讓模型靠大聲取勝」的整套防線。
