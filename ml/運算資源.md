```bash

# 對的（CUDA wheel）
/root/q01-gpu/.venv/bin/python              # torch 2.14.0+cu126, cuda True
```

**WSL 內呼叫格式**（從本機）：

```powershell
ssh qq134@SummerSnow wsl -d QBN -u root -- bash /mnt/c/Users/qq134/AppData/Local/Temp/<script>.sh
```
（把要跑的東西寫成 `.sh` → `scp` → 用上面這行執行。**不要用 `bash -c "..."`，引號會被 cmd 吃掉。**）

## 三、基準（同一顆 n=10、depth=8、batch=80、forward+backward）

| 裝置 | s/step | 相對 |
|---|---|---|
| 筆電 CPU | 0.3321 | 1.00× |
| **筆電 GPU（RTX 3060）** | **0.1972** | **1.68×** |
| 本機 CPU（滿載時） | 0.2934 | — |
| 本機 CPU（閒置時，推估） | ~0.29 | — |

**⇒ 我們的張量很小（≤ 1 MB），所以 GPU 只快 1.68×，不是十倍。**
**但真正的瓶頸是「本機 CPU 已 100%」——三個實驗在搶。**
把其中一個搬到筆電（CPU 或 GPU 都好）就能解除擁擠，這比糾結 GPU 倍率重要。

## 五、教訓（記錄下來）

**「測到 `cuda False`」不等於「沒有 GPU」——要確認你測的是哪個虛擬環境。**
本專案在筆電 WSL 裡有四個 venv（`q01-gpu`／`qbn-wsl`／`qbn`／`quafu`），
它們的套件版本**不一樣**，用途也不同。動任何 GPU 相關的事之前，先跑一次：

```bash
for v in /root/*/.venv; do echo -n "$v: "; $v/bin/python -c "import torch;print(torch.__version__, torch.cuda.is_available())" 2>/dev/null || echo "(無 torch)"; done
```
